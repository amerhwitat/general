# Chimera 3D/4D Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a new open-source-oriented 3D/4D digital-content-creation application under `Apple-Implementations/Chimera3D4D` that consolidates reusable 3D/4D concepts from the user's portfolio and provides modeling, sculpting, texturing, rigging, animation, motion capture/tracking, VFX, simulation, color, rendering, Apple, Flutter, and Web foundations.

**Architecture:** A C++ core owns scene/geometry/time/asset contracts; specialized engines expose modeling, sculpting, materials, animation, simulation, rendering and interchange APIs. Objective-C/Metal and Flutter provide Apple/mobile shells, while a WebGPU/WebGL frontend provides browser deployment. Open standards and permissively/open-source libraries are integrated by adapter boundaries with license/attribution records rather than copying proprietary DCC implementations.

**Tech Stack:** C++17/20, CMake, OpenGL/Metal/WebGPU, Objective-C, Flutter/Dart, TypeScript/JavaScript, OpenUSD, MaterialX, OpenColorIO, OpenImageIO, OpenVDB, OpenSubdiv, CGAL/libigl, glTF, USDZ, GitHub Actions.

**Spec:** `general/Apple-Implementations/Chimera3D4D/README.md`

## Global Constraints

- No proprietary ZBrush, Maya, 3ds Max, Cinema 4D or other closed-source implementation may be copied.
- Open-source dependencies must remain under their applicable licenses and be recorded in `THIRD_PARTY.md`.
- Apple IPA/macOS builds require macOS/Xcode and signing; repository CI may provide build jobs but this Linux/host environment cannot truthfully claim an IPA was produced.
- The first implementation is a functional foundation and adapter architecture, not a claim of complete feature parity with mature commercial DCC suites.
- 128D state metadata is represented as an optional scene/perception extension rather than replacing ordinary geometric coordinates.

## Discovery targets
Relevant public developer communities include Reddit programming communities, DEV Community, Hashnode, Medium, Hacker News, Lobsters, GitLab community spaces, CodeProject, Indie Hackers, Product Hunt, and relevant YouTube/video communities. Promotion should be manual or opt-in and must follow each site's rules; do not automate unsolicited posting, mass comments, DMs, or link spam.

## Publishing boundary
Public web publication can expose public repository URLs and descriptions. It does not automatically publish private repositories or create dark-web/Tor services. No credentials, private keys, recovery phrases, or server secrets belong in promotional material.

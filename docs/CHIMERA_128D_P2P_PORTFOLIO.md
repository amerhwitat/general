# Chimera 128D + P2P Portfolio Integration

This general repository follows the portfolio-wide Chimera semantic and peer interoperability contracts.

The 128D layer is semantic and extensible: geometry, time, observer/perspective, light/material response, events, objects, properties and interaction rules form the baseline, with perception/cognition and additional vector dimensions available as extensions.

P2P is opt-in and authenticated. Peers validate identity, capabilities, sequence/replay state, payload hashes and optional signatures. Supported logical messages are hello, request, response, publish, snapshot, delta and acknowledgement.

No unsolicited scanning, credential/private-key exchange, arbitrary executable transfer or remote command execution is part of the contract.

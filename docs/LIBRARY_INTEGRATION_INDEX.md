# Library-to-Mobile Integration Index

The mobile edition was designed using the saved Chimera II research corpus, including the Developer Guide, Mobile & Robotics Architecture Report, 8192-bit technical specification, Source-Code material, crash-dump/consolidated architecture material, compiler/CPU documents and prior Web/Desktop research.

Key sources currently indexed in the Library include:

- `Chimera II OS Developer Guide.txt`
- `Chimera_II_OS_Mobile_Robotics_Architecture_Report.pdf`
- `Chimera_II_OS_8192_High_Low_Level_Technical_Specification.pdf`
- `Source-Code.pdf`
- `Chimera II OS - crash dump.docx`
- `8192-ChimeraII-OS-Summary(1).docx`
- `CPU4096-ARM-and_X86.docx`
- `Chimera_II_OS_Comprehensive_Redesign_Research_Report.pdf`
- `Chimera II Web Runtime & Desktop Integration`
- `Integrating Linux 7.x, Retro Emulation, and Future Computing into Chimera II Web OS`

These sources establish ARM64/HAL portability, V-Core/resource isolation, zero-copy ownership, mobile power management, vector/tensor acceleration, the 128D cognitive layer and the separation between machine/cognitive/world planes. The Mobile Edition adds an Android-compatible application/service layer above those existing contracts.

Source status rule: supplied research is treated as architecture/design evidence, not as proof of production hardware performance. Hardware performance must be measured on target devices.

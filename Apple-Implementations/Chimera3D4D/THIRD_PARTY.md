# Third-party/open-source integration register

| Component | Intended use | License/source note |
|---|---|---|
| OpenUSD | scene graph, composition, animation, interchange, Hydra rendering boundary | Apache 2.0; https://github.com/PixarAnimationStudios/OpenUSD |
| MaterialX | portable material/shader graphs | Apache 2.0; https://github.com/AcademySoftwareFoundation/MaterialX |
| OpenColorIO | color management | BSD-3-Clause; https://github.com/AcademySoftwareFoundation/OpenColorIO |
| OpenImageIO | image I/O and texture pipeline | BSD-3-Clause; https://github.com/AcademySoftwareFoundation/OpenImageIO |
| OpenVDB | sparse volumes and VFX data | Apache 2.0; https://github.com/AcademySoftwareFoundation/openvdb |
| OpenSubdiv | subdivision surfaces | modified Apache 2.0; https://github.com/PixarAnimationStudios/OpenSubdiv |
| CGAL | robust computational geometry and mesh algorithms | GPL/commercial dual licensing; isolate behind optional adapter and comply with selected license: https://www.cgal.org/ |
| libigl | geometry processing algorithms | MPL-2.0; verify any copyleft/optional dependency boundaries: https://github.com/libigl/libigl |
| PlayCanvas Engine | browser WebGL/WebGPU runtime | MIT; https://github.com/playcanvas/engine |
| OpenDCC | architecture/training reference for USD-based DCC tooling | Apache 2.0; https://github.com/shapefx/OpenDCC |

No proprietary source from ZBrush, Maya, 3ds Max or Cinema 4D is included. Dependencies are adapters or documented references and must be pinned and license-reviewed before distribution.

# Training and developer guides

## Modeling and sculpting

Use the Blender Manual as the broad capability reference for modeling, sculpting, UVs, animation, physics, particles, rendering, compositing and motion tracking: https://docs.blender.org/manual/en/5.2/

## OpenUSD

The OpenUSD tutorials cover stage creation, properties, references/layers, variants, transformations, animation, shading and end-to-end workflows: https://openusd.org/dev/tut_usd_tutorials.html

OpenUSD developer guides cover coding/testing, color, Hydra 2.0 and MaterialX integration: https://openusd.org/dev/api/_developer__guides.html

## Geometry processing

CGAL provides robust triangulation, Boolean operations, mesh generation, point-set processing and spatial data structures: https://www.cgal.org/

libigl provides C++ geometry-processing primitives including differential geometry operators, topology structures and mesh utilities: https://igl.ethz.ch/code/

## DCC architecture

OpenDCC is a useful open-source reference for plugin-driven USD/Hydra DCC architecture and includes examples of sculpt, UV, paint, animation and render-view tooling: https://github.com/shapefx/OpenDCC

## Browser rendering

PlayCanvas provides an open-source WebGL/WebGPU runtime with glTF, animation, physics and XR support: https://github.com/playcanvas/engine

These resources are training/reference material. Their source and licenses must not be conflated with Chimera 3D/4D source code.

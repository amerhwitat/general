# Roadmap

## Foundation implemented

- scene/entity/mesh/time-sample contracts
- optional 128D metadata vector
- procedural cube and mesh translation
- sculpt brush/falloff primitive
- keyframe interpolation
- skeleton and motion-stream contracts
- PBR material and renderer abstractions
- particle, node and compositor foundations
- USD adapter boundary
- Objective-C + Metal macOS shell
- Flutter UI shell
- PlayCanvas Web viewport foundation
- CMake, PowerShell and macOS/Linux build scripts
- open-source/training/license documentation

## Next implementation layers

1. half-edge/topology kernel, subdivision and remeshing
2. multiresolution sculpting and symmetry/stamping
3. UV packing, texture painting and baking
4. MaterialX graph compiler and OCIO-managed color pipeline
5. GPU render graph and Metal/WebGPU backends
6. skeletal pose solver, IK/FK and retargeting
7. mocap/video tracking ingestion
8. particles, rigid bodies, cloth and volumetric simulation
9. OpenVDB volumes and compositing
10. OpenUSD live import/export and Hydra integration
11. asset browser, procedural graph editor and plugin SDK
12. collaborative hosted scene service and authenticated Chimera P2P integration
13. iOS/iPadOS touch/Apple Pencil sculpt workflow
14. macOS production build, signing and notarized distribution

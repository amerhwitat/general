# Safety and usage policy

- Crawl only public or explicitly authorized resources.
- Honor robots.txt and configured delay/concurrency limits.
- Keep crawl depth and page count bounded.
- Do not bypass authentication, CAPTCHAs, paywalls, access controls, or anti-bot mechanisms.
- Treat extracted addresses as public contact data, not consent to messaging.
- Comply with applicable privacy, anti-spam, data-protection, terms-of-service and copyright rules.
- Do not commit API keys, cookies, credentials, proxy credentials or personal datasets.
